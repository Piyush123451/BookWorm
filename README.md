
# Bookworm 📚

A personal book discovery and recommendation platform.

## About

Bookworm aims to help readers discover books, explore authors,
manage their personal libraries and find stories based on their interests.

## Current Features

- Homepage with a literary design
- Sample book catalogue
- Book search by title, author and genre
- Genre-based filtering
- Responsive layout

## Technologies

- HTML5
- CSS3
- JavaScript

## Upcoming Features

- Open Library API integration
- Google Books API integration
- Personal reading lists
- Python FastAPI backend
- Semantic book search using vector embeddings

## Project Status

Currently under development.
